## Shared contracts

### YplayerKit (O1)

- `YouTubeURL.videoID(from: String) -> Result<String, YouTubeURLError>` with `YouTubeURLError { notYouTube, playlistOnly, noVideoID }`: the same accepted forms and rejections as `crates/yplayer/src/ytid.rs` (`watch?v=` any param order with `www.`/`m.`/`music.` hosts and optional scheme, `youtu.be/ID`, `shorts/ID`, `live/ID`, `embed/ID`, bare 11-char id; `playlist?list=` or `watch?list=` without `v` → playlistOnly). Tests mirror every case in the Rust `ytid` tests.
- `OrbTargets.make(albums: [Album], maxBubbles: Int = 5) -> OrbTargets` with `bubbles: [OrbTarget]` (albums sorted by `lastUsedAt` desc, never-used last by name, first `maxBubbles`) plus a trailing `.newAlbum`, and `center: OrbTarget` (the most recently used album, else `.inbox` — the service creates "Inbox" for `album: nil`). `enum OrbTarget: Hashable { case album(id: Int64, name: String), inbox, newAlbum }`.
- `OrbLayout(targetCount: Int, radius: CGFloat = 92, bubble: CGFloat = 64, core: CGFloat = 72)`: bubble centers on an arc opening toward the screen's interior (the orb sits at the right screen edge, so bubbles fan to the left across angles 110°…250°, evenly spaced), `func target(at point: CGPoint) -> Int?` (nearest bubble within its radius; nil means the core when inside the core circle, else outside), `var size: CGSize` (panel content size fitting all bubbles). Pure geometry, tested.
- `DropPayload.url(from strings: [String]) -> String?`: the first string that parses as a YouTube URL (trimming whitespace, taking the first line), used for plain-text drags.

### App (O2)

- `AppModel.add(url: String, target: OrbTarget) async -> AddResult?` (`album: .id` for albums, `nil` for inbox; `play: true`; errors → toast, returns nil) and `AppModel.undoAdd(_ result: AddResult) async` (`album.remove` when `!wasInAlbum`, then `track.delete(toTrash: false)` when `wasNew`).
- `OrbController` (`@MainActor`, owned by `AppDelegate`): creates the panel once at launch and keeps it ordered out; `NSPanel(styleMask: [.borderless, .nonactivatingPanel])`, `level = .statusBar`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]`, `hidesOnDeactivate = false`, `isOpaque = false`, `backgroundColor = .clear`, `hasShadow = false`; content = `OrbDropView` (AppKit `NSView`, registered for `.URL`, `.string`, `.fileURL` is NOT registered) hosting `OrbView` (SwiftUI) in an `NSHostingView`; the drop view's own backing draws a near-invisible fill (alpha 0.01) over the drop zone so the window receives drags.
- `OrbDropView` (`NSDraggingDestination`): `draggingEntered` → `.copy` + bloom; `draggingUpdated` → hovered target via `OrbLayout.target(at:)`; `draggingExited` → collapse; `performDragOperation` → read `readObjects(forClasses: [NSURL.self])` then `.string` strings → `DropPayload`/`YouTubeURL`; invalid → shake + toast text "Not a YouTube video" (or "Playlists are not supported yet"), return false; `.newAlbum` → name prompt; else `model.add`.
- `OrbView` states (SwiftUI, driven by an `@Observable OrbState`): `hidden`, `armed` (a 72 pt glass orb with `music.note.list` symbol, gentle scale-in), `bloom(hovered: Int?)` (bubbles with album names, 1–2 lines, `.caption` bold, glass; hovered bubble scales 1.12 and tints accent; core shows the center target's name), `shake` (horizontal shake, 0.4 s), `toast(AddedToast)` (capsule "Added to <album> · Undo" for 6 s; Undo button calls `undoAdd` and shows "Removed" for 1 s). Spring animations only while visible.
- `DragWatcher`: global `NSEvent` monitors for `.leftMouseDragged` and `.leftMouseUp` (no Accessibility permission needed); on dragged, compare `NSPasteboard(name: .drag).changeCount` with the last seen value and inspect `types` only on change; show the orb (placement: right edge of the screen containing `NSEvent.mouseLocation`, vertically centered, inset 12 pt) when types contain `public.url` or `public.utf8-plain-text`; on mouse up → hide after 0.3 s unless a drop is in progress or a toast is showing; while the orb is visible and no mouse-up was seen, poll `NSEvent.pressedMouseButtons` every 0.1 s as a fallback and stop polling when hidden. Drags that start while our popover is shown are ignored (they are reorders inside the app).
- `NamePromptPanel`: a small key-capable borderless panel (activates the app) near the orb with a glass card: "New album" text field prefilled "New Album" (selected), Create (Return) / Cancel (Esc); Create → `album.create` then `add` to it; Cancel → nothing is added.
- Debug flags: `--snapshot-dir` gains `orb-armed`, `orb-bloom`, `orb-bloom-hover`, `orb-toast`, `orb-name-prompt`; new `--log-drags` writes each observed drag's pasteboard types to stderr (used to learn Safari tab drag types during verification).
- Performance: no timers while hidden (monitors only); the 0.1 s fallback poll exists only while the orb is visible during a drag; toast uses one 6 s sleep.

## Tasks

### O1 — Pure logic in YplayerKit + AppModel intents

- Files: `apps/macos/Sources/YplayerKit/Orb/{YouTubeURL,OrbTargets,OrbLayout,DropPayload}.swift`, `apps/macos/Tests/YplayerKitTests/OrbTests.swift`, `apps/macos/Sources/Yplayer/App/AppModel.swift` (add `add(url:target:)` and `undoAdd(_:)` only).
- Tests first: every `ytid.rs` case; `OrbTargets` ordering (recent first, never-used after by name, cap 5, `.newAlbum` last, center = most recent or `.inbox`); `OrbLayout` hit testing (each bubble center hits its index, core center hits nil-in-core, far point outside, bubbles fan left), size contains all bubbles; `DropPayload` picks the first YouTube URL among strings and trims.
- Commit: `SP3 O1: YouTube URL parsing, orb targets and layout, add/undo intents`.

### O2 — Orb panel, drop target, visuals, drag watcher, name prompt, undo toast

- Files: `apps/macos/Sources/Yplayer/Orb/{OrbController,OrbDropView,OrbView,OrbState,DragWatcher,NamePromptPanel}.swift`, `App/AppDelegate.swift` (create/retain `OrbController`; parse `--log-drags`), `Debug/DebugFixtures.swift` and `Debug/SnapshotRenderer.swift` (add orb states only).
- Acceptance: gates; snapshots reviewed (`orb-armed`, `orb-bloom`, `orb-bloom-hover`, `orb-toast`, `orb-name-prompt`). Real drags cannot be synthesized without Accessibility permission, so the live check is limited to: run the built app against a temp service (SP2 rules) with `--log-drags`, confirm via `CGWindowListCopyWindowInfo` that no orb window is on screen while idle, and confirm idle wakeups stay 0 (`top` for 20 s). Real drags are verified by the user in O3.
- Commit: `SP3 O2: drop orb panel with album bloom, drag watcher, name prompt, undo toast`.
